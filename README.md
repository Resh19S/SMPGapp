# PG / rental property management (owner web app)

Beds, rent, residents, complaints, move-outs, renewals and monthly profit &
loss for a PG/hostel owner and their staff. FastAPI + SQLAlchemy backend,
React + TypeScript frontend.

- **Run locally:** see "Local development" in `CLAUDE.md`.
- **Architecture & production plan:** `docs/ARCHITECTURE.md`
- **Security model:** `docs/SECURITY.md`
- **Tests:** `cd backend && .venv/bin/pytest` · browser checks in `e2e/`
